# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 2.0.0   | :white_check_mark: |
| < 2.0.0   | :x:                |

## Reporting a Vulnerability

If you have found a security issue with GraphQL-Ruby, please report it on GitHub: https://github.com/rmosolgo/graphql-ruby/security
